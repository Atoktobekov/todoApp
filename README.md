# 📋 Daily To-Do

✨ Простое и полезное приложение для ежедневного планирования и саморазвития.

---

## 🛠️ В разработке

Проект создан на **Flutter** и находится в стадии активной разработки.

---

## 💡 Идея

- 📅 Каждый день — это карточка со списком дел
- 🔔 Вечером (21:00–22:00) приходит напоминание заполнить задачи
- 🌙 После полуночи карточка архивируется (остается доступной)
- 📊 Статистика:
  - Всего задач
  - Выполненные задачи
  - Процент выполнения
- 🏆 Система достижений (ачивки) за прогресс и активность

---

## 🎯 Цель

Создать минималистичное и удобное приложение, которое помогает:
- 💭 Планировать день
- ✔️ Достигать целей
- 🔄 Развивать полезные привычки

---

## 🧰 Технологии

- 🦾Flutter + Dart
- 📦 Hive / SQLite (хранение данных)
- 🔔 flutter_local_notifications (локальные уведомления)

# 📋 Daily To-Do (EN)

✨ A simple and helpful app for daily planning and personal growth.

---

## 🛠️ In Development

This project is built with **Flutter** and is currently under active development.

---

## 💡 Idea

- 📅 Each day is a card with a list of tasks
- 🔔 Evening reminder (around 9–10 PM) to fill in your daily plan
- 🌙 After midnight, the card is archived (but still editable)
- 📊 Statistics:
  - Total tasks
  - Completed tasks
  - Completion rate
- 🏆 Achievement system for progress and consistency

---

## 🎯 Goal

Build a clean, minimalistic app that helps users:
- 💭 Plan their day
- ✔️ Achieve their goals
- 🔄 Build useful habits

---

## 🧰 Tech Stack

- 🦾 Flutter + Dart
- 📦 Hive / SQLite (data storage)
- 🔔 flutter_local_notifications (local reminders)

---

## 🗂️ Roadmap

- [ ] ✅ MVP: today's tasks, completion
- [ ] 🔔 Notifications
- [ ] 📦 Archiving and history
- [ ] 📊 Statistics
- [ ] 🏆 Achievements and gamification
